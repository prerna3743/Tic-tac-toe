# 🎮 Premium Tic Tac Toe

An interactive modern Tic Tac Toe game built using pure HTML, CSS, and JavaScript featuring a premium glassmorphism interface, neon animations, responsive gameplay, and real-time score tracking.

---

## ✨ Features

🚀 Modern UI/UX Design  
- Glassmorphism-inspired interface  
- Neon glow effects for players  
- Smooth animations and transitions  
- Responsive layout for desktop and mobile devices  

🎯 Gameplay Features  
- Real-time turn updates  
- Automatic win detection  
- Tie/draw detection  
- Highlighted winning combinations  
- Restart game functionality  

📊 Score System  
- Persistent in-session score tracking  
- Separate counters for:
  - Player X
  - Player O
  - Ties

⚡ Performance  
- Lightweight and fast  
- Built using Vanilla JavaScript  
- No external frameworks required
